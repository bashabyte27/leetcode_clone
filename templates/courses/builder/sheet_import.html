Good to know

Format
One tab is one course and one row is one item. The full contract is in docs/courses/SHEET_FORMAT.md.
Re-importing
Items are matched by code, so importing again updates them in place.
Removed rows
Never deleted here. The report lists them; delete them in the builder if you meant to.
Coding tasks
A CODING step with several problems becomes one coding step per problem.
Publishing
Importing never publishes. Students see a course only after you publish it from the course page.

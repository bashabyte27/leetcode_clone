{% if question_type == "mcq" %}

Enter at least two options. For a single-answer question, mark one correct option. For a multi-answer question, enable Allow multiple answers and mark every correct option. Programming language is optional for aptitude, quantitative, reasoning, and verbal questions; it is required only for Programming MCQs.

PDF format and example

Use a text-based PDF (not a scan). Start each question with === MCQ === and use these exact field names. Omit programming_language for non-programming MCQs.

=== MCQ ===
title: What is 2 + 2?
question_type: regular
category: quant
topic: Arithmetic
sub_topic: Addition
difficulty: easy
statement: Choose the correct answer.
explanation: Add the two numbers.
allow_multiple: false
option_1: 3
option_2: 4
correct_options: 2

Allowed values: question_type = regular or programming; category = aptitude, quant, reasoning, verbal, or programming; difficulty = easy, medium, or hard. Add option_3, option_4, etc. as needed. Set allow_multiple to true when several options are correct. correct_options is a comma-separated list such as 1,3; when allow_multiple is false, provide exactly one number.

{% else %}

Use the same unique question_key to connect each coding problem to its language and test-case rows. Every problem needs at least one supported language and one test case.

PDF format and example

Use a text-based PDF (not a scan). Start each problem with === CODING ===. Add one language block per language and one test-case block per case.

=== CODING ===
question_key: sum-two
title: Sum two numbers
coding_mode: scratch
topic: Algorithms
subtopic: Basics
difficulty: easy
statement: Read two integers and return their sum.
input_format: Two integers
output_format: Their sum

=== LANGUAGE ===
question_key: sum-two
programming_language: Python

=== TEST CASE ===
question_key: sum-two
input_data: 2 3
expected_output: 5
is_sample: true
weight: 1

For complete/fix, add code_snippet: in each language block, then the code, ending with END_CODE_SNIPPET on its own line. Allowed modes: scratch, complete, fix. Difficulty: easy, medium, hard.
